Trace → dataset → evaluate → optimize, all in the browser

Each section below is one numbered file. Read the file, then press its button. Follow them in order.

0. Settings config.js

Where MLflow runs (pnpm mlflow serves http://localhost:5000) and which experiment to use. Saved in localStorage.

1. Register the baseline prompt 01-register-prompt.js

Saves the agent's system prompt as version 1 in MLflow's Prompt Registry. Pressing it again makes a new version.

2. Run the agent 02-run-agent.js

Asks one question, with the latest prompt and three tools. MLflow records the run as a trace.

3. Create the dataset 03-create-dataset.js

10 questions with the expected answer facts and tools. 7 are for training (train), 3 are held back (test). Skipped if it exists.

4. Evaluate a prompt version 04-evaluate.js

Runs the agent on each question and scores every answer. Do it for version 1 to get your baseline.

5. Optimize the prompt 05-optimize.js

The model rewrites the prompt from its own failures on the train questions. The best rewrite is saved as a new version.

6. Compare on the test split 06-compare.js

Scores the old version and the newest one on the 3 test questions the optimizer never saw.
